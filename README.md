# Udemy-clone-flex-Project-Website
Developed a Udemy Clone using Flex, featuring a clean and user-friendly interface for online learning. Designed course sections, categories, and navigation layouts to provide a seamless browsing experience while improving skills in frontend development and responsive UI design.


Udemy Clone 🎓
📌 About the Project

The Udemy Clone is a frontend web development project inspired by the Udemy online learning platform. It recreates the look and feel of an online course website using HTML and CSS, with a focus on CSS Flexbox for layout design.

The website provides a clean, organized, and user-friendly interface where users can explore course categories, browse recommended courses, and view course information. This project was developed to improve my skills in frontend development, webpage structuring, styling, and creating flexible layouts.

✨ Features
Navigation Bar: A structured navigation bar for easy access to different sections of the website.
Search Section: A search interface inspired by online learning platforms.
Course Categories: Displays different learning categories to help users explore available topics.
Course Cards: Presents courses with images, titles, and other relevant details.
Recommended Courses: Highlights selected courses in an organized layout.
Popular Courses Section: Showcases courses in a visually appealing format.
Flexbox Layout: Uses CSS Flexbox to align and arrange elements efficiently.
Clean UI Design: Provides a simple and attractive interface inspired by Udemy.
Reusable Styling: Uses CSS classes to maintain consistent styles across the website.
Responsive Design: Focuses on flexible layouts that can be adapted for different screen sizes.

🛠️ Technologies Used
HTML5 – For structuring the webpage and organizing content.
CSS3 – For styling, colors, typography, spacing, and visual presentation.
CSS Flexbox – For arranging elements and creating flexible page layouts.
